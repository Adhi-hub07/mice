# mice 🐭

COPYMAPHUB loader — load it in your executor with the string below.

## Loading String

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Adhi-hub07/mice/main/copymaphub.lua"))()
```

### Alternative (if HttpGet is blocked)

```lua
loadstring(game:HttpGetAsync("https://raw.githubusercontent.com/Adhi-hub07/mice/main/copymaphub.lua"))()
```

## How to use

1. Open your executor (Krnl, Fluxus, Delta, Synapse, etc.)
2. Paste the loading string above
3. Click **Execute**
